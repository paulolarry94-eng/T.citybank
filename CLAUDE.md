# T.citybank — project memory for Claude

Owner goal: a systematic MT5 portfolio (Exness Zero account) with fortnightly payouts; aspiration 60–120% a
year. The job is to find out what is TRUE, not what looks impressive in a backtest.

## How to test anything: the Truth Lab
```bash
bash tools/bootstrap.sh
python3 research/truth/run.py research/truth/strategies/<idea>.py [--no-look]
```
Write new ideas as strategy files (`research/truth/strategies/TEMPLATE.py`). Do not write ad-hoc backtests
for new ideas; the lab's protocol is the standard (`research/truth/README.md`).

## Non-negotiable rules
1. Never claim code compiled, tests passed or an edge was verified unless it actually happened here.
   MQL5 cannot be compiled in this container: say "uncompiled source".
2. Fix markets, timeframes and parameter grids before seeing results. Choosing markets or settings after
   seeing results is hindsight, and it must be called out if done.
3. 2023–2025 is the final holdout: one logged look per strategy fingerprint. After a look, changed rules
   require a new strategy NAME.
4. Every result includes costs (spread + commission + slippage) and overnight swaps; report a
   low-cost swap-free profile separately, never instead.
5. Report rejections plainly, and say how many configurations were tried (deflated Sharpe).
6. Plain language for the owner: outcome first, numbers in tables, no hype.

## Memory: how the project learns across sessions
A SessionStart hook (`.claude/hooks/session-start.sh`) installs missing packages and prints the research
memory digest. Read it before acting. The memory lives in `research/truth/memory/`:
- `ledger.jsonl`: every idea ever tested. The Truth Lab appends every run automatically; studies done
  outside the lab must be added with `memory.record(...)` and a `source` field.
- `PRINCIPLES.md`: lessons with evidence and confidence (P1…). A principle changes only when new evidence
  arrives: edit it, keep the old text under "History", and note the change in the journal. Never delete silently.
- `OPEN_QUESTIONS.md`: the queue (Q1…). Owner ideas go here first, with FAMILY tags; answered questions move
  to "Answered" with a link to the evidence.
- `JOURNAL.md`: one entry per session (asked · done · learned with evidence · decisions · facts vs estimates · next).
- `LESSONS.md`: generated by `python3 research/truth/memory.py --render`; don't edit by hand.

Learning rules:
1. Before testing a new idea, check its priors (`python3 research/truth/memory.py --priors <tags>`). If earlier
   ideas with the same tags were all rejected, tell the owner before spending effort, and say why this one differs.
2. Only verified results become principles: a Truth Lab verdict or a reproducible study in the repo. Hunches
   become open questions, not principles.
3. Before ending a session that produced results: append a JOURNAL entry, update OPEN_QUESTIONS and
   PRINCIPLES if evidence changed them, run `--render`, commit and push.
